# Match Analyzer ⚽

Анализ футбольных матчей и поиск **value-ставок** — ставок, где коэффициент букмекера выше, чем «должен быть» по реальной вероятности исхода. Цель — найти **самые прибыльные и при этом наименее рискованные** стратегии и проверить их на истории, прежде чем ставить деньги.

## Как это работает

1. **Данные** — бесплатные CSV с [football-data.co.uk](https://www.football-data.co.uk): результаты + коэффициенты (Bet365, Pinnacle, среднее и лучшее по рынку) на П1/Х/П2 и тотал 2.5. 17 лиг (`python -m match_analyzer leagues`).
2. **Модель** — Пуассон / Диксон–Коулз: сила атаки и обороны каждой команды, домашнее преимущество; свежие матчи весят больше старых. Из модели считается вероятность каждого счёта → П1, Х, П2, ТБ 2.5, ТМ 2.5.
3. **Смешивание с рынком** — вероятность модели смешивается с «честной» вероятностью линии Pinnacle (без маржи). Это сильно снижает число ложных «перевесов».
4. **Отбор ставок** — ставим, только если перевес `p × кэф − 1` выше порога, кэф в заданном диапазоне, у команд достаточно истории, а модель не спорит с рынком слишком сильно.
5. **Размер ставки** — дробный Келли (¼) с лимитом 3% банка: при серии проигрышей банк не сгорает.
6. **Бэктест по ходу времени** — модель каждую неделю переобучается только на прошлых матчах, никакого заглядывания в будущее.
7. **Подбор стратегии** — перебор настроек, ранжирование по t-статистике (прибыль относительно разброса) и обязательная проверка на отложенном периоде, который не участвовал в подборе.

## Установка

```bash
pip install -r requirements.txt
```

## Использование

```bash
# 0. Демо без интернета (синтетическая лига)
python -m match_analyzer backtest --demo

# 1. Проверить стратегию на 5 последних сезонах АПЛ, Бундеслиги и Ла Лиги
python -m match_analyzer backtest --leagues E0 D1 SP1 --last 5 --save preds.csv

# 2. Подобрать лучшие настройки (быстро, по сохранённым прогнозам)
python -m match_analyzer optimize --selections preds.csv --out best_strategy.json

# 3. Получить ставки на ближайшие матчи по лучшей стратегии
python -m match_analyzer predict --leagues E0 D1 SP1 --strategy-file best_strategy.json
```

Основные параметры стратегии (`--help` у каждой команды):

| параметр | по умолчанию | смысл |
|---|---|---|
| `--markets` | `1X2 OU25` | рынки: исход матча и тотал 2.5 |
| `--min-edge` | 0.05 | минимальный перевес (5%) |
| `--min-odds` / `--max-odds` | 1.5 / 3.5 | диапазон коэффициентов — высокие кэфы дают длинные серии проигрышей |
| `--min-prob` | 0.30 | не ставить на маловероятные исходы |
| `--market-weight` | 0.5 | доля мнения рынка в итоговой вероятности |
| `--staking` | `kelly` | `kelly` или `flat` (фиксированно 1% банка) |
| `--max-stake` | 0.03 | максимум на одну ставку, доля банка |

## Как читать результат бэктеста

- **ROI** — прибыль на каждый поставленный рубль. Устойчивые +3…8% на длинной дистанции — уже очень хороший результат.
- **t-статистика** — насколько прибыль отличается от везения. Меньше ~2 — скорее всего, случайность.
- **Макс. просадка** — сколько стратегия теряла подряд от пика. Это мера «прогорания».
- Смотрите в первую очередь на **test_** колонки в `optimize`: это период, на котором настройки не подбирались.

## Важно

Букмекеры закладывают маржу, а линия Pinnacle очень точная — обыграть её на длинной дистанции сложно, и никакая модель не гарантирует прибыль. Если бэктест на реальных данных показывает ROI около нуля или в минусе, честный вывод — не ставить. Результаты в демо-режиме получены на синтетических данных с намеренно неточной линией и **ничего не говорят** о реальной прибыльности.
